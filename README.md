# DevHub 前端

Vue 3 + Vite，包含账号管理和本地开发工具。

## 启动与验证

```sh
npm ci
npm run dev
npm test
npm run build
```

开发环境的 `/api` 请求代理到 `http://127.0.0.1:8080`。

## 开发工具

通过侧栏进入，也可直接打开 `/#/tools/json` 或 `/#/tools/diff`。两个工具不依赖后端，导入的文件和输入内容仅在浏览器本地处理，不发送到服务器或持久化保存；切换菜单时保留内容，刷新页面后清空。

- **JSON 格式化**：单个编辑框，点击格式化或压缩直接更新框内内容，语法错误时保留原文；支持导入 JSON/TXT 文件、2/4 空格缩进、复制和下载。保留长整数、数值原始写法和重复键。输入上限 200 万字符，格式化结果上限 400 万字符。
- **文本对比**：输入、粘贴或左右分别导入文件后自动对比（150ms 防抖），直接在两个编辑框中用红色标出差异，相同时不显示提醒。支持交换左右和忽略行首尾空白。统一处理不同系统的换行符，额外空行以红色换行符标记。两侧合计上限 40 万字符、6000 行。

文件需为 UTF-8 编码的纯文本（如 TXT、JSON、Markdown、CSV 或代码文件），不支持 Word/PDF 或二进制文件。导入失败不会覆盖当前内容。

处理在 Web Worker 中运行，耗时过长时提示分段处理。复制需要浏览器支持剪贴板权限；复制失败时可手动选择结果复制。

## 网速测试

入口 `/#/tools/speed`。使用 `@cloudflare/speedtest` 连接 Cloudflare 公共测速节点，不需要 DevHub 后端提供测速接口。

- 点击开始后依次测量延迟、下载和上传，实时更新双仪表盘，并显示 Mbps / MB/s、抖动、忙时延迟和延迟曲线。
- 节点编号来自连接时服务器返回的 `cf-meta-colo`，未返回时显示自动选择。测速结果受节点、跨境线路、Wi-Fi 和代理影响，不能代表所有网站的速度。
- 本站稳定性参考规则：抖动 ≤10ms 为绿色，>10 且 ≤30ms 为黄色，>30ms 为红色。测试结束且至少有 10 个有效延迟样本才评级；失败、停止或缺失数据不会判为绿色。丢包率尚未接入。
- 按分段递增的数据量测速，计划有效载荷最多约 85MB（重试可能增加流量）；单请求超时 15 秒，整体超时 90 秒。短测试在高速网络下可能低估带宽。
- 不会自动开始测速；停止、离开工具页、页面隐藏或离线会取消请求。结果只保留在当前页面内存中。
- 关闭测速库的测量日志和结果上报，测速请求本身仍直接连接第三方节点。无需 API 密钥，不启用 TURN、丢包或额外探测。

验证命令仍为 `npm test` 和 `npm run build`，包含结果换算、评级边界、缺失样本、超时、取消和重测的测试。
